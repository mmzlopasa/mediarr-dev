# First steps

1. **Create the administrator.** The first account made on a new installation is the administrator.
2. **Add people.** Other accounts are made under **Admin → Users**.
3. **Install the app** and sign in with your server's address. See [mobile app](/features/mobile-app).
4. **Turn on backup** in the app, and choose which albums go to the server.
5. **Set up [backups](/administration/backup).** Backup from your phone is not a backup of your server.
6. **Bring in what you already have** with an [import](/features/import) or an [external library](/features/external-library).
