# Additions

These are turned on one by one under **Admin → Settings → Additions**.

- **Filters** for the photo editor. You can add your own as `.cube` files.
- **Documents**, a separate view of pictures that hold text, such as scans. It needs [smart search](/features/smart-search).
- **Kiosk**, a slideshow at a private address for a screen on the wall, on the web.
- **Webhooks**, which tell another service when something happens. Each message is signed, so the other side can check that it came from your server.
