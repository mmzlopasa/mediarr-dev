# Additions

These are turned on one by one under **Admin → Settings → Additions**. Each is off until you turn it on, and changes nothing until then.

- **Scheduled backup**, a backup every day at the hour you choose. See [Backup and restore](/administration/backup).
- **Filters in the editor** for the photo editor. You can add your own as `.cube` files.
- **Documents album**, a separate view of pictures that hold text, such as scans. It needs [smart search](/features/smart-search).
- **Family library**, where members share photos by rules they set themselves.
- **Webhooks**, which tell another service when something happens. Each message is signed in the `X-Mediarr-Signature` header, so the other side can check that it came from your server.
- **Kiosk for TV and tablet**, a slideshow at a private address for a screen on the wall, on the web.
- **Automatic descriptions and chat search**. See [Automatic descriptions](/features/automatic-descriptions).
