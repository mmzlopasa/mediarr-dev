# Import

Under **Admin → Settings → Import**, choose where from and into whose library. An import can be stopped and started again without making duplicates.

## From Immich

Enter the address of your Immich server and an API key from it. Photos, favourites, archive, albums and people come across. Immich's locked folder is left out, so move those yourself if you want them.

## From Google Takeout or iCloud

1. Unpack the export into a folder inside your [external library](/features/external-library).
2. Choose **Google Takeout** or **iCloud** and enter that folder.

An import stops by itself if the server's disk is nearly full.
