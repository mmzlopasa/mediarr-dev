# Docker

| File | Use |
| --- | --- |
| `docker-compose.yml` | Installation. With a `.env` made from `example.env`, this is all a server needs |
| `docker-compose.prod.yml` | Builds the images from this repository |
| `docker-compose.dev.yml` | Development with hot reload |
| `docker-compose.landing.yml` | The website |
| `docker-compose.docs.yml` | The documentation site |

See the [installation guide](https://docs.mediarr.app/install/docker-compose).
